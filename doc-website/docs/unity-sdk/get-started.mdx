# Get Started

## 프로젝트 설정

Unity용 Universal SDK는 iOS 또는 Android 플랫폼에서 Universal SDK를 사용할 수 있는 인터페이스를 제공합니다. Unity Editor에서 SDK를 사용하고 각 플랫폼으로 내보내려면 개발 환경에 다음 항목이 필요합니다.

## Unity 요구사항

- iOS 및 Android 모듈이 설치된 Unity 2019.4 이상
- Unity Personal, Unity Plus 또는 Unity Pro의 유효한 구독

## iOS 설치

Unity용 Universal SDK를 iOS에 통합하려면 다음 항목이 필요합니다.

- 배포 대상 iOS 12.0 이상
- Xcode 14 이상

iOS에서 Unity용 Universal SDK는 iOS용 Universal SDK의 래퍼로 동작합니다. iOS 프로젝트에는 프레임워크를 수동으로 추가해야 합니다. `UniversalSDKSwift.framework`는 `Plugins` 폴더에 있습니다.

## Android 설치

Unity가 Android 플랫폼으로 프로젝트를 빌드하려면 Android SDK가 설치되어 있어야 합니다. 이미 [Unity Android 개발 환경](https://docs.unity3d.com/Manual/android-sdksetup.html)을 구성했다면 Android SDK가 준비되어 있을 가능성이 높습니다.
